## 🔧 Основные команды сервера

### Общие

| Команда   | Описание                |
|-----------|-------------------------|
| `/kit`    | Открыть меню с наборами |
| `/quests` | Открыть меню заданиями  |

## Экономика

| Команда | Описание |
|---------|----------|
| `/balance` `/bal` | Проверить баланс |
| `/pay <ник> <сумма>` | Перевести деньги |

## Социальные

| Команда               | Описание                     |
|-----------------------|------------------------------|
| `/msg <игрок> <текст>` | Личное сообщение             |
| `/reply`          | Ответить на личное сообщение |

## 🏰 Lands

### Территория

| Команда           | Описание                |
|-------------------|-------------------------|
| `/l create <имя>` | Создать территорию      |
| `/l claim`        | Заприватить текущий чанк |
| `/l unclaim`      | Освободить текущий чанк |
| `/l delete`       | Удалить территорию      |
| `/l`              | GUI управления территорией |
| `/l map`          | GUI карта чанков        |
| `/l view`         | Подсветить границы чанка |
| `/l info`         | Информация о территории |
| `/l invite <игрок>`  | Пригласить игрока |
| `/l join <имя>`      | Вступить в территорию |
| `/l leave`           | Покинуть территорию |
| `/l trust <игрок>`   | Выдать доверенный доступ |
| `/l untrust <игрок>` | Убрать доступ |
→ [Подробнее о Lands](/plugins/lands/)

## ⚔️ AuraSkills

Команды с префиксом `/sk` также работают через алиасы `/skills` и `/skill`.

| Команда | Описание |
|---------|----------|
| `/skills` | Открыть меню навыков |
| `/stats` | Открыть меню характеристик |
| `/sk top [страница]` | Рейтинг игроков по сумме уровней навыков |
| `/sk top <навык> [страница]` | Рейтинг по конкретному навыку |
| `/sk rank` | Текущее место в рейтинге |
| `/sk sources <навык>` | Источники XP выбранного навыка |
| `/mana` | Показать текущую ману |
| `/abtoggle` или `/sk toggle` | Включить/выключить action bar |
| `/<навык>` | Открыть меню конкретного навыка (если включено в конфиге) |
→ [Подробнее об AuraSkills](/plugins/auraskills/)
