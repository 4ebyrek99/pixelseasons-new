# Список команд

Быстрый справочник по командам основных плагинов сервера. Подробное описание с примерами — на страницах плагинов.

---

## 🏰 Lands — Территории

### Территория

| Команда | Описание |
|---------|----------|
| `/l create <название>` | Создать территорию |
| `/l claim` | Захватить текущий чанк |
| `/l unclaim` | Освободить текущий чанк |
| `/l delete` | Удалить территорию |
| `/l setspawn` | Установить точку телепорта |
| `/l spawn <название>` | Телепорт к территории |
| `/l menu` | GUI управления территорией |
| `/l map` | Текстовая карта чанков |
| `/l view` | Подсветить границы в мире |
| `/l info` | Информация о территории под ногами |

### Участники

| Команда | Описание |
|---------|----------|
| `/l invite <игрок>` | Пригласить игрока |
| `/l join <название>` | Вступить в территорию |
| `/l leave` | Покинуть территорию |
| `/l kick <игрок>` | Выгнать игрока |
| `/l trust <игрок>` | Выдать доверенный доступ |
| `/l untrust <игрок>` | Убрать доступ |
| `/l role` | Управление ролями |

→ [Подробнее о Lands](/plugins/lands/)

## 🔧 Основные серверные команды

| Команда | Описание                |
|--------|-------------------------|
| `/kit` | Открыть меню с наборами |
| `/spawn` | Телепорт на спавн       |
| `/rules` | Правила сервера         |

| Команда | Описание | Доступ |
|---------|----------|--------|
| `/spawn` | Телепорт на спавн | Все |

## Экономика

| Команда | Описание | Доступ |
|---------|----------|--------|
| `/balance` `/bal` | Проверить баланс | Все |
| `/pay <ник> <сумма>` | Перевести деньги | Все |

## Социальные

| Команда | Описание |
|---------|----------|
| `/msg <ник> <текст>` | Личное сообщение |
| `/reply` `/r` | Ответить на ЛС |
## Защита территорий

| Команда          | Описание |
|------------------|----------|
| `/claim`         | Захватить чанк |
| `/unclaim`       | Освободить чанк |
| `/trust <ник>`   | Добавить доверенного |
| `/untrust <ник>` | Убрать доверенного |
| `/claiminfo`     | Инфо о территории |
| `/unclaim nall`  | Освободить все чанки |
