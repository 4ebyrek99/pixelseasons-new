Добро пожаловать на **PixelSeasons**! Следуй этому руководству, чтобы с первых минут не потеряться.

## Требования к версии игры

- Minecraft **Java Edition 26.2**(bedrock не поддерживается)

## Рекомендации

Для комфортной игры рекомендуется скачать подготовленный набор модов.

## Что важно знать с первых минут

### 🍂 Времена меняют всё
На сервере работает плагин **RealisticSeasons** — у каждого времени года своя погода, температура и правила для посевов. Зимой культуры не растут на открытой грядке, а в сильный мороз можно получить урон.

→ [Подробнее о временах года](/plugins/realistic-seasons/)

### 🏰 Защита территорий — обязательно
Без привата территории любой игрок может разрушить твою постройку.

→ [Подробнее о территориях](/plugins/lands/)

### ⚔️ Прокачка через AuraSkills
На сервере работает **AuraSkills**: ты прокачиваешь навыки за обычные действия (добыча, фермерство, бой, рыбалка и т.д.) и получаешь бонусы к статам, пассивные и мана-способности.

В первые часы игры открой меню навыков и выбери, что качать в приоритете.

→ [Подробнее об AuraSkills](/plugins/auraskills/)

## Полезные команды для старта

| Команда | Описание |
|---------|----------|
| `/kit start` | Получить стартовый набор |
| `/l create <имя>` | Создать территорию |
| `/l claim` | Захватить чанк |
| `/l map` | Карта захваченных чанков |
| `/skills` | Меню навыков и общий прогресс |
| `/stats` | Твои характеристики |
| `/sk sources <навык>` | Как получать XP для выбранного навыка |
| `/mana` | Текущая мана |
