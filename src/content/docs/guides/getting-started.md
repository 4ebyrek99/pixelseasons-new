# Как начать играть

Добро пожаловать на **PixelSeasons**! Следуй этому руководству, чтобы с первых минут не потеряться.

## Требования

- Minecraft **Java Edition 26.2**

## Подключение

1. Запусти Minecraft → **«Игра по сети»** → **«Добавить сервер»**
2. Введи адрес:

```
play.pixelseasons.net
```

3. Нажми **«Готово»** и **«Подключиться»**

## Первые шаги

После появления на сервере:

1. **Получи стартовый набор** — команда `/kit start` выдаст тебе начальные ресурсы автоматически

2. **Узнай текущее время года и температуру:**
   - **Время года и дата** — видны в **bossbar** (полоса над экраном)
   - **Температура** — отображается **над слотами быстрого доступа** (над 1-9 кнопками)

3. **Найди место для базы** — уйди подальше от спавна, чтобы найти нетронутые территории

4. **Защити территорию** как только построишь хоть что-то:
   ```
   /l create МоёПервоеЖилище
   /l claim
   ```
   (используй сокращение `/l` вместо `/lands`)

5. **Установи точку возврата** для быстрого возврата на спавн:
   ```
   /spawn
   ```
   Спавн — единственная точка телепортации на сервере

## Что важно знать с первых минут

### 🍂 Сезоны меняют всё
На сервере работает плагин **RealisticSeasons** — у каждого сезона своя погода, температура и правила для посевов. Зимой культуры не растут, а в сильный мороз можно получить урон.

→ [Подробнее о сезонах](/plugins/realistic-seasons/)

### 🏰 Защита территорий — обязательно
Без захвата территории любой игрок может разрушить твою постройку. Используй плагин **Lands**, чтобы защитить своё.

→ [Подробнее о территориях](/plugins/lands/)

## Полезные команды для старта

| Команда | Описание |
|---------|----------|
| `/kit start` | Получить стартовый набор |
| `/l create <имя>` | Создать территорию |
| `/l claim` | Захватить чанк |
| `/l map` | Карта захваченных чанков |
| `/spawn` | Телепортироваться на спавн |
| `/help` | Все доступные команды |

## Требования

- Minecraft **Java Edition 26.2**
- Лицензионная копия игры или пиратская версия

- Стабильное интернет-соединение

## Подключение к серверу

1. Запусти Minecraft и перейди в **«Игра по сети»**
2. Нажми **«Добавить сервер»**
3. Введи IP-адрес:

<div class="mc-ip">play.pixelseasons.net</div>

4. Нажми **«Готово»** и **«Подключиться»**

## Первые шаги

После подключения тебя встретит система обучения:

- 🌱 Выбери **стартовый биом** для своей базы
- 🗺️ Получи **карту начальной зоны** командой `/map`
- 🎒 Забери **стартовый набор** командой `/kit starter`
- 🏡 Установи свой **дом** командой `/sethome`

## Полезные команды для новичков

| Команда | Описание |
|---------|----------|
| `/spawn` | Телепортация на спавн |
| `/help` | Список всех команд |
| `/tpa <игрок>` | Запрос телепортации к игроку |
| `/discord` | Ссылка на Discord-сервер |
| `/rules` | Правила сервера |
