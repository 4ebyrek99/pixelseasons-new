**ShopShelves** — плагин магазинов на базе блока полки (*Shelf*).

## Как создать магазин

1. Установи полку на сундкук/бочку - **Shift + ПКМ**
2. Вставь товары в слоты и открой настройку цен, **ПКМ** по имени магазина.
3. Выставь цену покупки/продажи для нужных слотов.
4. После настройки другие игроки смогут торговать нажимая ЛКМ/ПКМ по полке.
