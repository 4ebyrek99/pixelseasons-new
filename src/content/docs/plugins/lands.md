**Lands** — плагин для защиты территорий. Вместо привычных чанков здесь работает система **Территорий (Lands)** — именованных владений, которые ты создаёшь и защищаешь. Никто не сможет сломать твои блоки, открыть сундуки или навредить питомцам без твоего разрешения.

## Основные понятия

- **Территория (Land)** — именованная территория, которую ты создаёшь
- **Чанк** — единица территории 16×16 блоков. Ты захватываешь чанки в свою территорию
- **Роли** — система прав внутри территории (владелец, доверенный, участник)

## Создание территории

```
/l create <название>
```
**Пример:**
```
/l create land_name
```
Территория создана. Теперь ты стоишь в незахваченном чанке — нужно захватить его.

```
/l claim
```
Захватывает чанк, в котором ты стоишь, и добавляет его в свою территорию. Переходи из чанка в чанк и повторяй команду, чтобы расширить территорию.

:::note[Лимит чанков]
Каждый игрок имеет ограниченное количество чанков.
:::

## Основные команды

### Управление территорией

| Команда | Описание |
|---------|----------|
| `/l create <название>` | Создать новую территорию |
| `/l claim` | Захватить текущий чанк |
| `/l unclaim` | Освободить текущий чанк |
| `/l menu` | Открыть GUI управления территорией |
| `/l map` | Показать карту чанков вокруг тебя |
| `/l info` | Информация о территории под ногами |
| `/l setspawn` | Установить точку появления территории |
| `/l spawn <название>` | Телепортироваться к территории |
| `/l delete` | Удалить свою территорию |

### Управление игроками

| Команда | Описание |
|---------|----------|
| `/l invite <игрок>` | Пригласить игрока в территорию |
| `/l join <название>` | Принять приглашение / вступить в территорию |
| `/l leave` | Покинуть территорию |
| `/l trust <игрок>` | Выдать доверенный доступ (может строить) |
| `/l untrust <игрок>` | Убрать доступ |
| `/l kick <игрок>` | Выгнать игрока из территории |
| `/l role` | Управление ролями участников |

### Просмотр и навигация

| Команда | Описание |
|---------|----------|
| `/l list` | Список всех территорий на сервере |
| `/l top` | Рейтинг территорий по размеру и активности |
| `/l view` | Подсветить границы захваченных чанков |

## Роли и права

Внутри территории есть система ролей с настраиваемыми правами:

| Роль | Возможности |
|------|-------------|
| **Владелец** | Полный контроль над территорией |
| **Со-владелец** | Управление участниками и настройками |
| **Участник** | Строительство и использование блоков |
| **Гость** | Только посещение (без разрушения) |

Тонкую настройку прав — через `/l menu` → **«Роли»**.

## Настройки территории (Flags)

В меню `/l` → **«Настройки»** можно включить или выключить:

| Флаг | Описание |
|------|----------|
| `PVP` | Разрешить PvP внутри территории |
| `MOB_DAMAGE` | Разрешить урон от мобов |
| `EXPLOSION` | Разрешить взрывы (TNT, крипер) |
| `FLY` | Разрешить полёт участникам |
| `ENTER_TITLE` | Показывать title при входе на территорию |

## Советы

:::tip[Совет новичку]
Захвати хотя бы 3×3 чанка вокруг своей базы сразу после постройки — одного чанка обычно мало!
:::

:::tip[Совет по картам]
Используй `/l view` для визуального отображения границ прямо в мире.
:::
