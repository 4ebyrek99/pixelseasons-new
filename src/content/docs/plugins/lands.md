**Lands** — плагин для защиты территорий. Вместо привычных чанков здесь работает система **Территорий (Lands)** — именованных владений, которые ты создаёшь и защищаешь. Никто не сможет сломать твои блоки, открыть сундуки или навредить питомцам без твоего разрешения.

## Основные понятия

- **Чанк** — единица территории 16×16 блоков
- **Территория** — именованная территория. Создаётся игроком и состоит из одного или нескольких чанков.
- **Область** — именованная область внутри основной территории, с отдельными правами доступа
- **Роли** — система прав внутри территории (владелец, участник, гость и другие, которые можно создать самому через GUI)

## Создание территории

```
/l create <имя>
```
**Пример:**
```
/l create land_name
```
Территория создана. Теперь чтобы заприватить следующие чанки используй команду:

```
/l claim
```
Приватит чанк, в котором ты стоишь, и добавляет его в твою территорию. Переходи из чанка в чанк и повторяй команду, чтобы расширить территорию.

:::note[Лимит чанков]
Каждый игрок имеет ограниченное количество чанков.
:::

## Основные команды

### Управление территорией

| Команда                | Описание                                   |
|------------------------|--------------------------------------------|
| `/l`                   | Открыть GUI управления территорией         |
| `/l create <название>` | Создать новую территорию размером 3x3 чанка |
| `/l claim`             | Заприватить текущий чанк                   |
| `/l unclaim`           | Освободить текущий чанк                    |
| `/l info`              | Информация о территории                    |
| `/l delete <имя>`      | Удалить свою территорию                    |

### Управление игроками

| Команда              | Описание |
|----------------------|----------|
| `/l invite <игрок>`  | Пригласить игрока в территорию |
| `/l join <имя>`      | Принять приглашение / вступить в территорию |
| `/l leave`           | Покинуть территорию |
| `/l trust <игрок>`   | Выдать доверенный доступ (может строить) |
| `/l untrust <игрок>` | Убрать доступ |

### Просмотр и навигация

| Команда | Описание                                   |
|---------|--------------------------------------------|
| `/l list` | Список всех территорий на сервере          |
| `/l top` | Рейтинг территорий по размеру и активности |
| `/l view` | Подсветить границы заприваченных чанков    |

## Роли и права

Внутри территории есть система ролей с настраиваемыми правами:

| Роль         | Возможности |
|--------------|-------------|
| **Владелец** | Полный контроль над территорией |
| **Админ**    | Управление участниками и настройками |
| **Участник** | Строительство и использование блоков |
| **Гость**    | Только посещение (без разрушения) |

Права ролей на территории можно настроить через `/l` → **«Роли»**.

## Настройки территории (Nature flags)

В меню `/l` → **«Природные флаги»** можно настроить взаимодействие территории с окружающим миром.


## Настройки территории (Role flags)

В меню `/l` → **«Флаги роли»** можно настроить права для каждой роли.


## Советы

:::tip[Совет новичку]
Захвати хотя бы 3×3 чанка вокруг своей базы сразу после постройки — одного чанка обычно мало!
:::

:::tip[Совет по картам]
Используй `/l view` для визуального отображения границ прямо в мире.
:::
