# ⚔️ AuraSkills

**AuraSkills** (ранее **Aurelium Skills**) — плагин RPG-прогрессии. Он добавляет навыки, характеристики, способности и систему наград за прокачку.

## Как работает система

- Игрок получает XP за действия в мире (добыча, фермерство, бой, рыбалка, зачарование и другие источники).
- XP повышает уровень конкретного навыка.
- Уровни навыков дают бонусы к статам, открывают пассивные и мана-способности, а также могут выдавать дополнительные награды сервера.

## Навыки по умолчанию

В AuraSkills есть 11 базовых навыков:

| Навык | Команда меню |
|------|---------------|
| Farming | `/farming` |
| Foraging | `/foraging` |
| Mining | `/mining` |
| Fishing | `/fishing` |
| Excavation | `/excavation` |
| Archery | `/archery` |
| Defense | `/defense` |
| Fighting | `/fighting` |
| Agility | `/agility` |
| Enchanting | `/enchanting` |
| Alchemy | `/alchemy` |


## Основные команды игрока

Команды с префиксом `/sk` также работают через алиасы `/skills` и `/skill`.

| Команда | Что делает                                        |
|---------|---------------------------------------------------|
| `/skills` | Открывает меню навыков                            |
| `/stats` | Открывает меню характеристик                      |
| `/sk top [страница]` | Рейтинг игроков по сумме уровней навыков          |
| `/sk top <навык> [страница]` | Рейтинг по конкретному навыку                     |
| `/sk rank` | Показывает твой ранг в рейтинге                   |
| `/sk sources <навык> [sortType]` | Показывает источники XP для навыка                |
| `/mana` | Показывает текущую ману                           |
| `/abtoggle` или `/sk toggle` | Включает/выключает личный action bar с ХП и маной |
| `/sk claimitems` | Открывает меню получения невзятых наград          |
